SproutGit gives every piece of work — yours or an AI agent's — its own real
working directory on disk, backed by [git worktrees](https://git-scm.com/docs/git-worktree),
instead of forcing everything through one checked-out branch. That means no
stashing, no context-switching, and no agents fighting over the same files.
